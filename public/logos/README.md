# Logos

Drop real logo files here to replace the auto-generated monogram tiles.

Expected filenames (SVG preferred; PNG works if you change the extension in `Logo.tsx`):

- samsung.svg
- iit-indore.svg
- galway.svg
- iit-madras.svg
- srmist.svg
- meetspace.svg

If a file is missing, the UI falls back to a clean monogram (e.g. "SR", "II") —
nothing breaks. Use the official brand assets only where you're entitled to
(employer/affiliation logos for a personal CV are standard nominative use).
